# Configuration Feature overview

- download a new model (show errors) by filling in a model name
- progress bar for the download. 

- be able to see all available models per analysis type (summary, ner, topics) in a dropdown
- Be able to set the default model for an analysis type


- Be able to set a minimum length for processing
- Be able to set the amount of characters for SUMMARY and  TOPICS.
- Be able to set the amount of characters for NER.
